# 水下考古潜水记录

- `index.html`：潜水标记平面图。直接打开使用，点击平面图添加标记，支持筛选、编辑、删除、时间线和导出JSON。
- `review/index.html`：声呐复核台（直接打开使用）。声呐筛出异常目标后登记复核，通过后生成下水任务。

## 复核台业务规则

- **登记**：测线号、目标编号、坐标、置信等级（水深、备注选填）。
- **重传**：同测线号 + 同目标编号再次提交，资料一致沿用首次结果；资料变化转“待复核”，原记录继续有效，复核后采纳或维持。
- **下水任务**：复核通过后生成，绑定接触点、潜次、申报人；同一接触点只保留一条未结束任务；撤回必须填写原因。
- **改动联动**：采纳的新资料若改动测线号或坐标，未结束任务转“待重排”并解绑原潜次（可重新排期）；已下潜任务留档不动。

业务代码按三个文件拆分：

| 文件 | 职责 |
| --- | --- |
| `review/judgment.js` | 判定：重传判别、待复核裁决、字段差异、是否需要重排 |
| `review/tasks.js` | 任务：台账与任务存储、生成/撤回/重排/留档的生命周期 |
| `review/page.js` | 页面：表单、待复核队列、台账、任务面板的渲染与交互 |
