# 声呐异常复核与下水任务

考古队用声呐先筛异常目标，流程：**接触点登记 → 复核台判定 → 生成下水任务**。

直接打开 `index.html` 使用（数据存浏览器 localStorage）。三个业务文件各管一块：

| 文件 | 职责 |
| --- | --- |
| `judgment.js` | 判定：登记测线号、目标编号、坐标、置信等级；同线同编号重传资料一致沿用首次结果；资料变化转待复核，原记录继续有效；确认异常 / 排除 / 采用新资料 / 维持原记录 / 资料更正 |
| `tasks.js` | 任务：复核过后绑定接触点、潜次、申报人生成下水任务；同一接触点只留一条未结束任务；撤回必填原因；测线或坐标改动自动重排未结束任务；已下潜按当时资料快照留档，不再受改动影响 |
| `page.js` | 页面：平面图取坐标与标记、声呐回传登记表、复核台、任务板、JSON 导出 |
| `index.html` | 页面骨架与样式，不含业务逻辑 |

## 业务规则要点

- **重传去重**：同「测线号 + 目标编号」且坐标/置信一致的重传，沿用首次登记结果，不产生新记录。
- **资料变化**：坐标或置信变化（以及人工测线更正）排队待复核；采用前原记录继续有效。
- **判定**：首次复核可「确认异常」或「排除」；有待复核资料时先「采用新资料」或「维持原记录」。
- **任务**：只有已确认异常的接触点可生成任务；同一接触点存在未结束任务时拒绝再开。
- **重排**：采用的新资料包含测线或坐标改动时，在办任务自动计数并移到队列末尾，「重新排入队列」后恢复；仅置信变化不重排。
- **留档**：登记下潜即结束任务，保存当时的测线/坐标/置信快照，之后接触点改动不影响该档。
